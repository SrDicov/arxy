# arxy — corre software de Arch en cualquier distro, a velocidad nativa

> La documentación canónica vive en [README.md](README.md) (inglés); esta página es solo un puntero (la traducción 1:1 se eliminó: se desfasaba en cada cambio).

```bash
git clone https://github.com/SrDicov/arxy && cd arxy && sudo ./install.sh && sudo arxy setup
```

O en una línea (cualquier distro; instala dependencias, arxy, la imagen y actualiza todo):

```bash
curl -fsSL https://raw.githubusercontent.com/SrDicov/arxy/main/install-remote.sh | sudo bash
```
